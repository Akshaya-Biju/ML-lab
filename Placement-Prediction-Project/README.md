# Placement Prediction Using Machine Learning

## Project Overview

This project predicts whether a student will be placed or not based on academic performance, skills, internships, projects, certifications, and other factors.

The project applies Machine Learning classification algorithms and compares their performance.

## Dataset Features

- CGPA
- Internships
- Projects
- Workshops/Certifications
- Aptitude Test Score
- Soft Skills Rating
- Extracurricular Activities
- Placement Training
- SSC Marks
- HSC Marks

Target Variable:

- Placement Status (Placed / Not Placed)

## Machine Learning Algorithms Used

1. Logistic Regression
2. K-Nearest Neighbours (KNN)
3. Naive Bayes

## Performance Comparison

| Model | Accuracy |
|---------|----------|
| Logistic Regression | 79.45% |
| KNN | 75.80% |
| Naive Bayes | 79.35% |
